# Nepal Flood Map — Field Worker Guide

> **For:** Nepal Army, Nepal Police, Armed Police Force, NDRRMA, humanitarian workers, journalists
> **Purpose:** How to use this dashboard in the field, even without internet

## Quick Start (2 minutes)

1. **Open** the dashboard URL in your mobile browser (Chrome/Safari)
2. **Add to Home Screen** → works like an app, works offline
3. **Map shows:** flood origin, affected locations, flow path, severity markers
4. **Tap markers** for details: coordinates, time hit, casualty info

## What Each Section Tells You

### 🗺️ Map (Cesium 3D)
- **Red pulsing dot** = Glacier collapse origin (Lhende Khola)
- **Colored circles** = Affected locations
  - 🔴 Red = Critical (Rasuwagadhi, Timure, Syapru Besi)
  - 🟠 Orange = High (Dhunche, Trishuli Bazar, Nuwakot)
  - 🟡 Yellow = Medium (Devighat, Chitwan)
- **Red line** = Flood flow path (southward)

### 📊 Live Dashboard
- Deaths, missing, rescued (auto-refreshes every 60s)

### 🛰️ Satellite Comparison

### 📥 Export Data

## Offline Use (PWA)

The dashboard installs as a Progressive Web App:

1. **First load** while online → caches automatically
2. **After installation** → works without internet
3. **Map tiles** → cached after first view
4. **Static data** → always available (verified Aug 29 2026)
5. **Live data** → updates when connection restored

**To install:**
- Android: Chrome → Menu → "Add to Home Screen"
- iOS: Safari → Share → "Add to Home Screen"

## Using Coordinates in the Field

### Copy Coordinates
1. Open **Coordinate Table** (bottom of page)
2. Tap **Copy** next to any location
3. Pastes as `lat,lng` (e.g., `28.2776,85.3776`)

### Use in GPS/Garmin
1. Open GPS app → Navigate to Coordinates
2. Paste `28.2776,85.3776`
3. Save as waypoint

### Use in QGIS
1. Export **GeoJSON** from dashboard
2. Open QGIS → Layer → Add Layer → Add Vector Layer
3. Select downloaded `.geojson` file
4. Style by severity field

### Use in Google Earth
1. Export **KML** from dashboard
2. Open Google Earth → File → Open
3. Select downloaded `.kml` file

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Map won't load | Check internet; try Leaflet fallback |
| Data not refreshing | Pull down to refresh; check connection |
| Can't export | Enable pop-ups; try different browser |
| Offline mode not working | Re-install PWA while online |
| Coordinates wrong | Verify datum (WGS84) in GPS |
